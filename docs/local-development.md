# Local development checklist

Install Node.js 22+ with npm, run `npm install`, configure `.env.local` using `.env.example`, and apply the Supabase migration. Auth/storage/usage still need Supabase; a local Supabase instance avoids a hosted dependency. Start with `npm run dev:mock` or use `INFERENCE_MODE=mock` and `npm run dev`.

1. Sign in and open Studio. Enable camera and mic. Verify raw camera preview before creating a persona; no inference request is needed for preview.
2. Select each OS/browser-exposed camera and microphone. This includes virtual/phone cameras and capture cards if their software registers them as MediaDevices inputs. Labels come from the browser, with numbered placeholders before permission. Switch cameras and confirm the same microphone stays selected and its mute state is retained. Switch microphones and confirm the same camera remains live. Reload and confirm preferences persist.
3. Disconnect and reconnect a device. Confirm its list entry refreshes, the remaining input stays active, and another input can be selected without reload. Deny microphone permission and confirm raw video still plays. Deny camera permission or occupy a camera exclusively in another app and confirm an actionable error and successful retry after releasing it.
4. Create a persona, affirm rights, upload face/optional voice assets, and prepare it in mock mode. Start/stop sessions and open the signed output URL in a second same-origin browser tab. Switch inputs while streaming and check that output follows the new tracks. Mock mode shows original media and performs no transformation.
5. Stop the session, set `LOCAL_INFERENCE_API_URL=http://localhost:8000`, start a separately implemented worker following [the contract](inference-contract.md), and run `npm run dev:local`. Re-prepare the persona with this worker. Enable only supported transformations; start AI and receive actual model output when available. Replace worker models behind the same API while keeping the frontend unchanged.
6. Stop the worker before starting AI, or stop it during a session. Confirm Studio reports inference unavailable and keeps raw preview usable. Switch to raw preview explicitly while AI is active. Check camera ready / requesting permission / camera unavailable independently of AI connecting / active / unavailable.
7. With a local worker providing output signaling, add the signed output URL as an OBS Browser Source on the same computer. Test video, audio, watermark, token expiry, and revocation after Stop Live. The mock BroadcastChannel bridge works only between tabs in the same browser context; actual OBS requires the local or remote worker's viewer connection. No cloud GPU is required for a local worker.

## Free allowance and usage

All three modes use the existing Free allowance (30 streaming minutes per month), persona quotas, quality restrictions, and atomic usage accounting. Mock sessions debit streaming minutes too. The application currently measures credits as streaming-minute allowance; it has no separate timed-trial, monetary credit ledger, or payment checkout. Those features need their own billing implementation.

On a disposable local Supabase account, inspect Billing before and after a short mock session. Confirm elapsed usage is recorded once on stop; repeated stop requests must not debit twice. Test a reload and stop of an existing session. With usage near the monthly allowance, verify the worker receives only the remaining seconds, the session expires at that budget, and a fully exhausted allowance rejects a new session. Verify a Free user cannot select High Quality or create a second persona. Use the local Supabase SQL editor to seed/delete usage only for your disposable test account; never edit production usage to run this test.

`npm test` checks allowance boundaries, local-worker requests, track replacement, device removal, permission failures, stale preferences, rapid selection races, and cleanup. Actual device drivers, Supabase integration, and model/OBS output require the manual checks above.
